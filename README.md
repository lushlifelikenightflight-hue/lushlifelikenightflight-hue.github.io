# LAST ENCORE ブラウザー無料体験版

公開用静的ビルド。正本はプロジェクトの browser/。dist/ を配信します。
管理用マップエディターと個人セーブは含みません。
操作: PCはマウス・キーボード、スマホは縦画面のタッチ操作。
セーブ・写真・設定は各ブラウザー内に保存されます。
素材の権利表示は dist/LICENSES.txt を参照。

公開先: https://lushlifelikenightflight-hue.github.io/
GitHub Pages の Actions が dist/ だけを配信します。
Sites は256MiBの入力上限により不採用（未配信）。
ゲーム全体の配布データは約382MBです。実機の性能・通信状態によって読み込み時間が変わります。
